# License simple flow

1. Tum apni site pe Shortner HQ chalata ho (admin + keys).
2. Customer ko ZIP milta hai (adha code).
3. Woh ZIP `public_html` mein nikaalta hai, domain kholta hai.
4. Site poochti hai: license key + tumhari HQ URL.
5. Key sahi + pehli site = activate. HQ se baaki files site pe aa jati hain.
6. Same key doosri site pe = band. Message: Contact admin.

Ek key = jitne max domains tum ne key banate waqt likhe (default 1).
